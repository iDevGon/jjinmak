# 찐막 앱 아이콘 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Electron’s default icon with one generated for 찐막 and apply the same visual source to runtime, Windows, and macOS app icons.

**Architecture:** Generate one transparent 1024×1024 PNG master with a text-free flat mint power-button badge. Keep that PNG inside the shared desktop package for the runtime window, and derive native `.ico` and `.icns` files from it for Electron Packager. Only the shared Electron window setup and packaging script change; the platform adapters and UI do not.

**Tech Stack:** Built-in ImageGen, PNG with alpha, macOS `sips`/`iconutil`, ImageMagick `magick` or `convert` for `.ico`, Electron 44, `@electron/packager`, Node built-in test runner, Playwright Electron smoke test.

### Task 3: Derive the platform-native icon files

**Files:**
- Create: `assets/jjinmak.ico`
- Create: `assets/jjinmak.icns`

- [ ] **Step 1: Create the macOS iconset from the master**

Run these commands from the repository root:

```bash
rm -rf tmp/icon-build/jjinmak.iconset
mkdir -p tmp/icon-build/jjinmak.iconset
for size in 16 32 64 128 256 512 1024; do
  sips -z "$size" "$size" packages/desktop/src/ui/app-icon.png --out "tmp/icon-build/jjinmak.iconset/icon_${size}x${size}.png" >/dev/null
done
cp tmp/icon-build/jjinmak.iconset/icon_32x32.png tmp/icon-build/jjinmak.iconset/icon_16x16@2x.png
cp tmp/icon-build/jjinmak.iconset/icon_64x64.png tmp/icon-build/jjinmak.iconset/icon_32x32@2x.png
cp tmp/icon-build/jjinmak.iconset/icon_256x256.png tmp/icon-build/jjinmak.iconset/icon_128x128@2x.png
cp tmp/icon-build/jjinmak.iconset/icon_512x512.png tmp/icon-build/jjinmak.iconset/icon_256x256@2x.png
cp tmp/icon-build/jjinmak.iconset/icon_1024x1024.png tmp/icon-build/jjinmak.iconset/icon_512x512@2x.png
iconutil -c icns tmp/icon-build/jjinmak.iconset -o assets/jjinmak.icns
rm -rf tmp/icon-build
```

Expected: `assets/jjinmak.icns` is created and `file assets/jjinmak.icns` reports an Apple icon image.

- [ ] **Step 2: Create the Windows ICO with preserved alpha**
