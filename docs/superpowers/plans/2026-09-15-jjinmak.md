# 찐막 Implementation Plan

**Goal:** 다음 한 판 종료 시 롤·선택한 디스코드·PC를 종료하는 Windows 앱.
**Architecture:** 순수 게임 상태 판정과 OS 작업을 분리한다. Electron 메인에서만 권한 작업 수행.
**Tech Stack:** Electron, Node built-in test runner, HTML/CSS, Playwright Electron smoke test.

## 1. 판정과 외부 경계
- [x] `test/core.test.cjs`: 게임 추적·오인 방지·1회 실행·옵션 고정·취소 테스트.
- [x] `test/adapters.test.cjs`: LCU 명령행 파싱·세션 정규화·OS 명령·플랫폼 차단 테스트.
- [x] `npm test`로 기능 부재 확인 후 `src/core.cjs`, `src/lcu.cjs`, `src/windows.cjs` 구현.
- [x] `npm test` 통과 확인. 총 24개, ID 누락과 비동기 취소 포함.

## 2. 데스크톱 앱
- [x] `src/main.cjs`: 단일 인스턴스, 비중첩 폴링, 신뢰된 IPC, 종료 동작·취소.
- [x] `src/preload.cjs`: 제한된 UI API만 노출.
- [x] `src/ui/index.html`, `style.css`, `renderer.js`: 큰 원형 토글, 상태, 옵션, 카운트다운.
- [x] `scripts/smoke-ui.cjs`로 모의 이벤트를 통한 실제 Electron 창 동작과 화면 확인. 최소화 창 복원 포함.

## 3. 배포·인계
- [x] `scripts/package.mjs`로 Windows x64 실행 폴더 생성.
- [x] `README.md`: 실행 방법, 패키징, 동작 정의, 실환경 검증 항목과 한계.
- [x] 모든 테스트와 패키지 내용 확인. Windows x64 PE 헤더, ASAR와 소스 일치 검증.

실제 Windows 롤·디스코드·PC 종료 검증은 이 Mac 개발 환경에서 수행할 수 없다.
README의 실환경 검증 체크리스트는 미완료 상태로 유지한다.
