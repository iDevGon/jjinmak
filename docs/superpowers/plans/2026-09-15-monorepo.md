# macOS / Windows 모노레포

목표: npm workspaces로 운영체제별 앱·배포를 구분하고 공통 화면과 게임 로직을 재사용한다.
사용자 승인 범위: 모노레포 구현과 지정 원격 저장소 연결. 커밋·푸시는 별도 요청이 없어 수행하지 않는다.

- [x] 기존 24개 테스트가 통과하는 기준점 확보.
- [x] `packages/core`로 판정·제어·LCU 이동. LCU는 OS별 프로세스 탐색을 주입받는다.
- [x] `packages/desktop`로 Electron 실행기·화면 이동. 기존 시각 스타일 유지.
- [x] `apps/windows`로 기존 Windows 어댑터·앱 진입점 이동.
- [x] `apps/macos` 추가. 현재 사용자 프로세스만 탐색·종료. 정해진 shutdown 명령만 관리자 승인으로 실행.
- [x] macOS 테스트: 실행 파일의 전체 경로, 공백이 포함된 프로세스명, 다른 사용자 제외, Discord 옵션, ESRCH/권한 오류, 플랫폼 오실행 차단.
- [x] 31개 테스트, 두 앱 모의 UI 테스트, macOS 읽기 전용 실제 탐색 검증.
- [x] 앱별 패키지 구성으로 Windows x64 및 macOS Apple Silicon/Intel 빌드.
- [x] origin 연결·lockfile·문서·배포 산출물 확인. 실제 강제 종료는 검증 중 실행하지 않았다.

패키징은 임시 디렉토리에 선택한 앱과 두 공통 패키지만 모아 packager에 전달한다.
소스의 workspace symlink가 배포 파일에서 외부 경로를 참조하지 않도록 독립 파일로 복사한다.
macOS는 `osascript`의 관리자 승인으로 `/sbin/shutdown -h now`를 요청한다.
UI는 이 승인 가능성을 안내하고, 취소/실패를 표시한다. 권한을 저장하거나 시스템 설정을 바꾸지 않는다.
데모는 명시적인 `--demo`에서만 켜며 잘못된 OS의 앱을 실행하면 실제 기능을 거부한다.

검증 기록: `npm ci` 후 31개 테스트 통과. macOS·Windows 진입점 각각의 Electron UI 모의 테스트 통과.
현재 Mac의 실제 프로세스 탐색 결과 롤 0개. macOS arm64 패키지 실제 모드 기동·기본 OFF 상태 확인.
Mac 개발 빌드는 ad-hoc 서명하며, 원본 Electron에서 상속된 runtime 플래그를 명시적으로 해제한다.
배포용 Developer ID 서명·공증, 실게임 종료, 실제 시스템 종료는 검증하지 않았다.
