# 찐막 설계

사용자가 승인한 검토 방향을 구현한다. 신규 독립 폴더에 만든다.

## 구조
Electron 메인 프로세스가 LCU HTTPS 조회, 상태 판단, Windows 프로세스 종료를 담당한다.
격리된 로컬 렌더러는 상태 표시, 활성화, 두 옵션, 종료 취소만 요청할 수 있다.
WPF는 Windows 네이티브에 적합하지만 현재 개발 환경에 .NET이 없다.
Tauri는 작은 배포 크기가 장점이지만 Rust 툴체인과 Windows 빌드 준비가 추가된다.
현재 환경에서 테스트하고 Windows 실행 폴더를 생성할 수 있는 Electron을 선택한다.

## 상태와 동작
OFF → 다음 게임 대기 → 동일 gameId의 InProgress 관찰 → 종료 상태 2회 확인 → 실행 → OFF.
활성화 직전 새 상태 조회를 완료해 이미 진행 중인 gameId는 제외한다.
종료 상태는 PreEndOfGame 또는 EndOfGame이며 실제 최신 클라이언트 호환성은 검증 항목이다.
종료 상태라도 gameId가 없거나 변경되면 실행하지 않는다.
ChampSelect·Reconnect·None·통신 오류는 종료 근거로 쓰지 않는다.
모니터링 중 다른 게임 시작이 보이면 잘못된 종료를 피하기 위해 자동 해제한다.
일반 모드에서는 LeagueClient 및 렌더러를 종료하고 옵션에 따라 Discord도 종료한다.
PC 모드에서는 먼저 롤과 선택한 Discord를 종료하고 30초 후 Windows 종료를 요청한다.
PC 종료 카운트다운은 앱 소유이며 취소 또는 앱 종료로 폐기된다.
PC 종료 옵션을 켤 때 저장되지 않은 작업 손실을 알리는 확인을 제공한다.

## 안전과 실패 처리
Windows 이외 및 --demo 모드에서는 실제 OS 작업을 수행하지 않는다.
LCU 인증 정보는 실행 중 프로세스 명령행에서 찾아 메모리에만 보관한다.
로컬 127.0.0.1 HTTPS 요청에서만 자체 서명 인증서를 허용한다. 전역 TLS 설정은 건드리지 않는다.
종료 대상은 현재 Windows 세션에 속한 명시적 프로세스 이름 목록으로 제한한다.
권한 오류는 사용자에게 표시하며 자동으로 관리자 권한을 요청하거나 무한 재시도하지 않는다.
Riot Client와 Vanguard는 종료 대상에서 제외한다.
창을 닫으면 앱과 감시가 종료된다. 최소화하면 감시가 유지된다.

## 검증
Node 테스트: 한 판 추적, 기존 게임 제외, 닷지, 튕김, 재접속, 중복 이벤트, 불일치 ID, 취소.
LCU 파싱/HTTP 실패 및 Windows 명령 테스트: OS 호출 경계만 대체해 실제 종료를 방지한다.
Electron 모의 실행 UI 테스트: 토글, 옵션 확인, 한 판 종료, 카운트다운 취소, 스크린샷.
Windows x64 실행 폴더를 패키징한다. 실제 Windows 롤, Discord, PC 종료는 별도 실환경 체크리스트로 남긴다.
