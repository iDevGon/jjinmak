# 찐막 v0.2.0

Windows와 macOS에서 창을 닫아도 게임 감시를 계속 유지하고, OS 로그인 시 자동 실행을 선택할 수 있는 프리릴리스입니다.

## 다운로드

| 사용 환경 | 다운로드 |
|---|---|
| Windows 10/11 · x64 | [찐막 Windows 다운로드](https://github.com/iDevGon/jjinmak/releases/download/v0.2.0/jjinmak-0.2.0-windows-x64.zip) |
| Mac · Apple Silicon (M 시리즈) | [찐막 Mac Apple Silicon 다운로드](https://github.com/iDevGon/jjinmak/releases/download/v0.2.0/jjinmak-0.2.0-macos-arm64.zip) |
| Mac · Intel | [찐막 Mac Intel 다운로드](https://github.com/iDevGon/jjinmak/releases/download/v0.2.0/jjinmak-0.2.0-macos-x64.zip) |

파일 무결성 확인: [SHA256SUMS.txt](https://github.com/iDevGon/jjinmak/releases/download/v0.2.0/SHA256SUMS.txt)

## 변경 사항

- 창의 X 버튼(Windows) 또는 빨간색 닫기 버튼(macOS)을 눌러도 앱과 롤 감시가 백그라운드에서 계속 실행됩니다.
- Windows 하단 트레이와 macOS 상단 메뉴바에서 `찐막 열기`로 창을 다시 표시하고 `앱 종료`로 실제 종료할 수 있습니다.
- `컴퓨터를 켜면 찐막 시작` 옵션으로 Windows/macOS 로그인 시 앱을 자동 실행하고 창을 표시할 수 있습니다. 기본값은 OFF입니다.
- Windows/macOS 앱 아이콘과 트레이 아이콘을 추가했습니다.
- 자동 실행 정책, 창 닫기, 트레이 생존, 양 플랫폼 모의 UI 흐름을 포함한 테스트를 보강했습니다.

## 검증 범위와 제한

- 자동 테스트 41개와 macOS·Windows 모의 UI 테스트를 통과했습니다.
- 실제 롤 경기 종료 감지, 프로세스 강제 종료, PC 종료, OS 로그인 후 자동 실행은 실환경 확인이 필요합니다.
- Windows 배포자 서명은 없고, Mac 앱은 로컬 개발용 ad-hoc 서명만 사용합니다. Apple Developer ID 서명·공증은 포함하지 않습니다.
- PC 종료 시 열려 있는 프로그램이 강제로 닫힐 수 있어 저장하지 않은 작업이 사라질 수 있습니다.
