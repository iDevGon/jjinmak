# 찐막 v0.1.1

롤 게임 상태 감지를 주기적 폴링에서 웹소켓 이벤트 방식으로 바꾼 프리릴리스입니다.
실게임 검증 전인 초기 테스트용 버전입니다.

## 다운로드

| 사용 환경 | 다운로드 |
|---|---|
| Windows 10/11 · x64 | [찐막 Windows 다운로드](https://github.com/iDevGon/jjinmak/releases/download/v0.1.1/jjinmak-0.1.1-windows-x64.zip) |
| Mac · Apple Silicon (M 시리즈) | [찐막 Mac Apple Silicon 다운로드](https://github.com/iDevGon/jjinmak/releases/download/v0.1.1/jjinmak-0.1.1-macos-arm64.zip) |
| Mac · Intel | [찐막 Mac Intel 다운로드](https://github.com/iDevGon/jjinmak/releases/download/v0.1.1/jjinmak-0.1.1-macos-x64.zip) |

파일 무결성 확인: [SHA256SUMS.txt](https://github.com/iDevGon/jjinmak/releases/download/v0.1.1/SHA256SUMS.txt)

GitHub가 자동으로 제공하는 `Source code`는 소스 파일입니다. 앱 실행에는 위 ZIP을 사용하세요.

## 실행 방법

1. ZIP의 압축을 전부 풉니다.
2. Windows에서는 폴더 안의 `찐막.exe`를 실행합니다. exe만 따로 옮기면 실행되지 않습니다.
3. Mac에서는 압축을 푼 폴더의 `찐막.app`을 실행합니다.
4. 옵션을 고른 뒤 큰 ‘찐막’ 버튼을 켜고 다음 게임을 시작합니다.

Node.js 별도 설치는 필요하지 않습니다. 자세한 사용 방법은 ZIP에 포함된 `사용설명.md`와
[README](https://github.com/iDevGon/jjinmak/blob/v0.1.1/README.md)를 참고하세요.

## 변경 사항

- LCU 웹소켓으로 게임 세션 변경 이벤트를 받아 주기적 상태 조회를 제거했습니다.
- 연결·재연결 직후와 찐막 활성화 시 현재 상태를 조회합니다.
- 추적한 판의 종료 이벤트를 받으면 1.5초 후 API로 같은 판의 종료를 재확인합니다.
- 중복 이벤트·연결 끊김·늦은 응답으로 인한 오종료를 방지합니다.
- 연결이 끊기면 4초 후 인증 정보를 다시 찾아 재연결합니다.

게임 도중 켜면 현재 판은 건너뛰고 다음 판에 적용합니다. 실행 후에는 찐막이 자동으로 꺼집니다.

## 검증 범위와 제한

- 자동 테스트 41개와 양쪽 앱 진입점의 모의 UI 테스트를 통과했습니다.
- 로컬 HTTPS·웹소켓 서버에서 인증, 상태 이벤트, 종료 재확인을 검증했습니다.
- Mac Apple Silicon 패키지의 데모 기동을 확인했습니다.
- Mac Apple Silicon·Intel 앱의 개발용 서명 무결성을 확인했습니다.
- **실제 롤 경기 종료 감지·디스코드 강제 종료·PC 종료는 아직 실환경에서 검증하지 않았습니다.** Windows 및 Mac Intel에서 앱 실행도 별도 확인이 필요합니다.
- Windows 앱은 배포자 서명이 없고, Mac 앱은 로컬 개발용 ad-hoc 서명만 있습니다. Apple Developer ID 서명·공증은 없어 운영체제에서 실행 경고 또는 제한이 발생할 수 있습니다.
- Mac 시스템 종료에는 관리자 승인 창이 나타날 수 있으며 승인해야 종료됩니다.
- PC 종료 시 다른 프로그램도 닫히므로 **저장하지 않은 작업이 사라질 수 있습니다.**
- Riot의 LCU API는 외부 앱용으로 공식 지원되지 않아 롤 패치 이후 수정이 필요할 수 있습니다. Riot 공식 승인 제품이 아닙니다.
