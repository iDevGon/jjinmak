# 찐막 v0.3.0

LCU 게임 상태 감지를 주기적 폴링에서 웹소켓 이벤트 방식으로 바꾼 프리릴리스입니다.

## 다운로드

| 사용 환경 | 다운로드 |
|---|---|
| Windows 10/11 · x64 | [찐막 Windows 다운로드](https://github.com/iDevGon/jjinmak/releases/download/v0.3.0/jjinmak-0.3.0-windows-x64.zip) |
| Mac · Apple Silicon (M 시리즈) | [찐막 Mac Apple Silicon 다운로드](https://github.com/iDevGon/jjinmak/releases/download/v0.3.0/jjinmak-0.3.0-macos-arm64.zip) |
| Mac · Intel | [찐막 Mac Intel 다운로드](https://github.com/iDevGon/jjinmak/releases/download/v0.3.0/jjinmak-0.3.0-macos-x64.zip) |

파일 무결성 확인: [SHA256SUMS.txt](https://github.com/iDevGon/jjinmak/releases/download/v0.3.0/SHA256SUMS.txt)

GitHub가 자동으로 제공하는 `Source code`는 소스 파일입니다. 앱 실행에는 위 ZIP을 사용하세요.

## 변경 사항

- LCU 웹소켓으로 게임 세션 변경 이벤트를 받아 주기적 상태 조회를 제거했습니다.
- 연결 및 재연결 직후, 그리고 찐막 활성화 시 현재 상태를 조회합니다.
- 추적한 게임의 종료 이벤트를 받으면 1.5초 후 HTTPS API로 같은 게임의 종료를 재확인합니다.
- 초기 조회 중 도착한 이벤트를 순서대로 처리하고, 중복 이벤트·연결 끊김·늦은 응답으로 인한 오종료를 방지합니다.
- 기존 Windows 트레이, macOS 메뉴바, 로그인 자동 실행, 앱 아이콘, 게임 종료 안전장치는 유지됩니다.

## 검증 범위와 제한

- 자동 테스트 51개와 macOS·Windows 모의 UI 테스트를 통과했습니다.
- 로컬 TLS HTTPS·웹소켓 서버에서 인증, 구독, 이벤트 순서, 재연결, 종료 재확인을 검증했습니다.
- Windows x64, macOS arm64, macOS x64 패키징을 확인했습니다.
- **실제 롤 경기 종료 감지·디스코드 강제 종료·PC 종료는 아직 실환경에서 검증하지 않았습니다.**
- Riot의 LCU API는 외부 앱용으로 공식 지원되지 않아 롤 패치 이후 수정이 필요할 수 있습니다. Riot 공식 승인 제품이 아닙니다.
- Windows 앱은 배포자 서명이 없고, Mac 앱은 로컬 개발용 ad-hoc 서명만 있습니다. Apple Developer ID 서명·공증은 없어 운영체제에서 실행 경고 또는 제한이 발생할 수 있습니다.
- PC 종료 시 다른 프로그램도 닫힐 수 있으므로 저장하지 않은 작업이 사라질 수 있습니다.
